## 📐 精确坐标计算

### 真实道路数据来源
```
=== Edge3坐标信息 (from training_Town03.net.xml) ===
车道3_5: 起点(205.58, 279.86) 终点(205.27, 394.37) - 右侧慢车道
车道3_4: 起点(209.08, 279.87) 终点(208.77, 394.38) - 中间车道
车道3_3: 起点(212.58, 279.88) 终点(212.27, 394.39) - 左侧快车道
```

### 车道中心精确计算

#### Lane 1 (右侧慢车道 - 3_5)
```python
起点X: 205.58m
终点X: 205.27m
中心X = (205.58 + 205.27) / 2 = 205.425m ≈ 205.43m
```

#### Lane 2 (中间车道 - 3_4)
```python
起点X: 209.08m
终点X: 208.77m
中心X = (209.08 + 208.77) / 2 = 208.925m ≈ 208.93m
```

#### Lane 3 (左侧快车道 - 3_3)
```python
起点X: 212.58m
终点X: 212.27m
中心X = (212.58 + 212.27) / 2 = 212.425m ≈ 212.43m
```

### 车道宽度验证 ✅
```python
车道1到车道2: 208.93 - 205.43 = 3.50m ✅
车道2到车道3: 212.43 - 208.93 = 3.50m ✅

标准车道宽度: 3.5m ✅ 完全符合！
```

### 道路边界计算

#### 道路总宽度
```python
3条车道 × 3.5m = 10.5m
```

#### 边界坐标（考虑车道半宽1.75m）
```python
右边界 = 车道1中心 - 车道半宽
       = 205.43 - 1.75 
       = 203.68m ≈ 203.7m

左边界 = 车道3中心 + 车道半宽
       = 212.43 + 1.75 
       = 214.18m ≈ 214.2m

道路总宽度 = 214.2 - 203.7 = 10.5m ✅
```

## 💡 技术要点

### 为什么选择3条车道？

虽然Edge3有6条车道 (3_0 ~ 3_5)，但根据用户需求：
- **使用车道**: 3_5, 3_4, 3_3 (右侧3条)
- **原因**: NGSIM数据通常只有3车道
- **好处**: 简化映射，减少复杂度

### 为什么道路边界比实际车道范围宽？

```python
实际车道范围: 205.27m ~ 212.58m (7.31m)
设置边界范围: 203.7m ~ 214.2m (10.5m)

原因:
1. 车道线两侧各预留半个车道宽度 (1.75m)
2. 允许车辆在车道内有横向偏移
3. 符合真实驾驶行为
```

### 精确到小数点后2位的原因

```python
205.425m → 205.43m (保留2位)
208.925m → 208.93m (保留2位)
212.425m → 212.43m (保留2位)

原因:
1. SUMO坐标精度通常为厘米级 (0.01m)
2. 过高精度无实际意义
3. 便于调试和验证
```
